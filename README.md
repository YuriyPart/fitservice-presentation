# Сайт-презентация франшизы FIT SERVICE

Одностраничный сайт в формате презентации: 14 полноэкранных слайдов,
scroll-snap листание (колесо / свайп / стрелки клавиатуры), прогресс-бар,
точки-навигация, адаптив под десктоп / планшет / мобильные.

## Состав

| Файл | Назначение |
|---|---|
| `index.html` | Готовый сайт-презентация. Один самодостаточный файл (~2 МБ), все изображения зашиты внутрь как base64. Больше ничего не нужно. |
| `anketa.html` | Анкета партнёра (15 шагов, пошаговый опросник в том же стиле). Тоже один файл, без картинок. Кнопка «Заполнить анкету партнёра» на последнем слайде презентации должна вести сюда (`ANKETA_URL`). |
| `src/template.html` | Исходник с плейсхолдерами `{{имя-картинки}}` вместо base64 — правки удобнее делать здесь. |
| `src/assets/` | Все изображения (webp/jpg/png). |
| `src/build.py` | Сборка: подставляет ассеты в template и перезаписывает `index.html`. Запуск: `python3 build.py`. |

## Деплой

Статический файл, бэкенда нет. Положить `index.html` в корень любого
хостинга / поддомена (например, `present.fitauto.ru`). Внешние запросы —
только Google Fonts (Oswald, Inter) и Яндекс.Метрика.

## Перед запуском — 2 обязательные правки

В начале `<script>` внизу `index.html` (или `src/template.html` + пересборка):

```js
var METRIKA_ID = 'XXXXXXXX';                          // номер счётчика Яндекс.Метрики
var ANKETA_URL = 'https://forms.yandex.ru/XXXXXXXX';  // ссылка на анкету (URL размещённого anketa.html)
```

В `anketa.html` — свои настройки в начале скрипта:

```js
var METRIKA_ID = 'XXXXXXXX';  // тот же счётчик
var SUBMIT_URL = '';          // endpoint для приёма ответов (POST JSON)
```

Ответы анкеты собираются в JSON `{form, submitted_at, answers:{вопрос: ответ}}`
и отправляются POST-ом на `SUBMIT_URL` (webhook CRM, Google Apps Script,
телеграм-бот — на усмотрение). Пока `SUBMIT_URL` пуст, форма показывает экран
«Спасибо» и пишет JSON в консоль — подключить приёмник обязательно до запуска.
Вопрос «Какое направление бизнеса?» показывается только если в вопросе о бизнесе
выбрано «Есть бизнес» или «Был бизнес».

Пока `METRIKA_ID` не заменён на число, счётчик не инициализируется (сайт работает без аналитики).
Счётчик создаётся в metrika.yandex.ru; в его настройках включить **Вебвизор**
(в коде уже передаётся `webvisor: true`, карта кликов и точный отказ включены).

## Цели Яндекс.Метрики

Сайт шлёт `ym(ID, 'reachGoal', ...)`. В Метрике завести цели типа
«JavaScript-событие» с этими идентификаторами:

| Идентификатор | Событие |
|---|---|
| `slide_1` … `slide_14` | просмотр слайда N (первый раз за визит) — воронка глубины |
| `deck_finished` | долистал до последнего слайда (анкета) |
| `cta_contacts` | клик по кнопке «Свяжитесь с нашими менеджерами» (слайд 12) |
| `anketa_click` | клик «Заполнить анкету партнёра» (слайд 14) — основная конверсия |
| `contact_click` | любой клик по контакту менеджера (параметры: manager, type) |
| `anketa_open` / `anketa_start` / `anketa_q_N` / `anketa_submit` | анкета: открыл / начал заполнять / дошёл до вопроса N / отправил — воронка заполнения |
| `click_phone` / `click_email` / `click_telegram` / `click_site` | детализация по типу контакта (параметр manager) |

## Правки контента

Контакты менеджеров — слайд 13 (`<section class="slide s13">`), обычные
ссылки `tel:` / `mailto:` / `https://t.me/…` с атрибутами `data-goal` и `data-mgr`.
Тексты слайдов — обычный HTML. Цвета — CSS-переменные в `:root`
(`--orange: #FE4F01`, `--blue: #0A60C7`, `--black: #0A0A0A`).

Если правите `src/template.html` — не забудьте `python3 src/build.py`
и деплойте свежий `index.html`.
